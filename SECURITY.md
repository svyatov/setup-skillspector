# Security policy

## Reporting a vulnerability

Report security issues through GitHub private vulnerability reporting, at https://github.com/svyatov/setup-skillspector/security/advisories/new. It keeps the report private until there is a fix to disclose.

If the advisory form is unavailable, email leonid@svyatov.com instead. Do not open a public issue for a security report.

The maintainer acknowledges a report within one week of receiving it.

A finding in SkillSpector itself belongs upstream, at https://github.com/NVIDIA/skillspector/security.

## Supported versions

Only the latest release gets fixes.
